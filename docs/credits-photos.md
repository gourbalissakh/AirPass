# Crédits médias

Toutes les photographies et la vidéo de ce prototype proviennent de
Wikimedia Commons et sont réutilisables. Cette page tient lieu
d'attribution, comme les licences CC BY et CC BY-SA l'exigent.

Les fichiers sont servis depuis `web/public/` ; leur inventaire applicatif
(chemins, légendes, cadrage) est dans `web/src/medias.js`.

**29 médias** au total.

  repartagée sous la même licence. Les images sont utilisées telles quelles,
